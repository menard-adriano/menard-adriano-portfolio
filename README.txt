MENARD ADRIANO - MULTIMEDIA CREATIVE PORTFOLIO
 
A portfolio website for Menard Adriano written in PHP, HTML/CSS and a little JavaScript.
It showcases the creative works such as filmmaking, graphic designs and creations, and video editings.


TECH STACK
- HTML5
- CSS3 (custom properties, grid, flexbox, animations, the <dialog> element)
- JavaScript (plain, no libraries: scroll animations, project pop-ups, menu)
- PHP (page template and content from data.php; no framework, no database)


REQUIREMENTS

- PHP 7.4 or newer (the live site is built with PHP 8.3)
- A modern web browser with JavaScript turned on
  (recent Chrome, Edge, Firefox or Safari)
- XAMPP, or any other local PHP web server, to run it on your computer
- An internet connection, for the fonts and icons. Without it the site still
  works, but uses default fonts and the icons don't show.


RUN IT LOCALLY

1. Install XAMPP and open the XAMPP Control Panel.
2. Click Start next to Apache.
3. Get the code from GitHub:
   https://github.com/menard-adriano/menard-adriano-portfolio
   Click the green "Code" button, then "Download ZIP", and extract it.
4. Copy the extracted folder into C:\xampp\htdocs
5. Open your browser and go to:
   http://localhost/Menard_Adriano_Portfolio/
6. To update the site, edit data.php, save, and refresh (Ctrl+F5).
